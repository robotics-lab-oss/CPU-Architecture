# Instruction Set

## Version

v0.1

## Instruction Table

| Opcode | Mnemonic | Description |
|--------|----------|-------------|
| 0000 | NOP   | No operation |
| 0001 | LOAD  | Load data from memory |
| 0010 | STORE | Store data to memory |
| 0011 | MOV   | Move data between registers |
| 0100 | ADD   | Add |
| 0101 | SUB   | Subtract |
| 0110 | AND   | Bitwise AND |
| 0111 | OR    | Bitwise OR |
| 1000 | XOR   | Bitwise XOR |
| 1001 | NOT   | Bitwise NOT |
| 1010 | CMP   | Compare |
| 1011 | JMP   | Unconditional jump |
| 1100 | JZ    | Jump if zero |
| 1101 | JNZ   | Jump if not zero |
| 1110 | IN    | Read input |
| 1111 | HALT  | Stop execution |
